JavaScript adalah bahasa pemrograman yang berjalan di browser untuk membuat halaman web interaktif, misalnya memvalidasi form, merespons klik, mengubah isi halaman secara dinamis, dan menampilkan animasi.

jQuery adalah library JavaScript yang menyederhanakan penulisan kode, terutama untuk memilih elemen HTML (DOM), menangani event, membuat efek/animasi, dan AJAX, dengan kode yang jauh lebih pendek.

Perbedaan dari JavaScript adalah bahasa pemrogramannya, sedangkan jQuery hanyalah library yang dibuat dengan JavaScript. jQuery butuh dipanggil lewat file/CDN, JavaScript murni tidak. Kode jQuery lebih ringkas ($("#id").hide() vs document.getElementById("id").style.display = "none"). Dengan JavaScript murni mempunyai kontrol penuh tanpa dependensi tambahan, sedangkan jQuery lebih praktis tapi menambah ukuran file dan ketergantungan.
